Introduction:

	•	Problem Statement:
“Cryptocurrency markets are highly volatile, with altcoin prices often influenced by Bitcoin’s movements, particularly its dominance in the market. Understanding how altcoins correlate with Bitcoin can provide deeper insights into market trends and help traders make informed decisions.”
	•	Importance:
“This is important because Bitcoin dominance is a key metric used to assess market sentiment, and identifying correlations can help detect patterns for risk management and portfolio diversification.”
	•	Research Question:
“How do altcoin price movements correlate with Bitcoin’s price movements and dominance in the cryptocurrency market?”
	•	Brief Approach:
“We plan to fetch real-time and historical cryptocurrency price data from public APIs, store the data in PostgreSQL, and use correlation analysis to identify relationships between Bitcoin and major altcoins.”


Data Description:

	•	Source:
“The data will be fetched from public APIs of major cryptocurrency exchanges like Binance, Coinbase, or Kraken using HTTP GET requests.”
	•	Scope:
“The dataset will include price data for Bitcoin and at least 5 popular altcoins over the last year.”
	•	Details:
“We estimate this will result in hundreds thousands of records per asset, with fields such as timestamps, open prices, high prices, low prices, close prices, and volume.”
	•	Database:
“The data will be stored in a PostgreSQL database to ensure efficient querying and analysis.”


Methodology:

	•	Tools:
“We will use Python for data collection and storage, leveraging libraries like requests for API calls and psycopg2 for PostgreSQL interactions. For analysis, We’ll use pandas for preprocessing and numpy or scipy for correlation computations.”
	•	Analysis Type:
“This project involves descriptive analysis to summarize the data and diagnostic analysis to explore how Bitcoin’s dominance affects altcoin price movements. For deeper insights, if time permits, predictive analysis may be incorporated to assess future correlations.”
	•	Workflow:
		•	Fetch cryptocurrency price data in real-time using APIs.
		•	Save the data to PostgreSQL, ensuring data quality and consistency.
		•	Use Python for preprocessing and exploratory analysis.
		•	Perform statistical correlation analysis between Bitcoin and altcoins.
		•	Visualize the results using libraries like matplotlib or seaborn to illustrate trends and correlations.


Expected Outcomes:

	•	“We expect to find varying degrees of correlation between Bitcoin and altcoins, with some altcoins showing strong dependence on Bitcoin dominance while others may display weaker or no correlation.”
	•	“These insights can inform traders about potential market trends and help in crafting data-driven trading strategies.”
